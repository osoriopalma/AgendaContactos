## 📖 Sobre el proyecto

**Agenda de Contactos** es una aplicación de escritorio desarrollada como parte del proceso de aprendizaje y práctica en **Java y Programación Orientada a Objetos**.

El proyecto permite gestionar información personal de diferentes contactos desde una interfaz gráfica, facilitando tareas como el registro, consulta, modificación, búsqueda y eliminación de información.

El objetivo es desarrollar una aplicación funcional que combine la lógica de programación con una interfaz orientada a la experiencia del usuario.

## 🚀 Instalación y ejecución

### 📋 Requisitos

Antes de ejecutar el proyecto es necesario contar con:

* ☕ **Java JDK 21**
* 🔧 **Maven**
* 🌱 **Git**

### 1️⃣ Clonar el repositorio

```bash
git clone https://github.com/osoriopalma/AgendaContactos
```

### 2️⃣ Entrar al directorio

```bash
cd Agenda
```

### 3️⃣ Compilar el proyecto

```bash
mvn clean install
```

### 4️⃣ Ejecutar la aplicación

Abre el proyecto desde tu entorno de desarrollo y ejecuta la aplicación.
